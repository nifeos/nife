# What rented metal costs: the appendices to notes/rented-metal.md

[`notes/rented-metal.md`](../rented-metal.md) carries the four requirements, a summary and a
recommendation for each architecture, and the case for a second provider. It also carries the price
of milestone 225 (run the soak on radon, argon and xenon)'s legs, the recommendation table and BUGS.
These files carry the tables, sources and arguments its prose budget has no room for. Every figure in them was read on 2026-09-23, except `oracle-a1.md`, read 2026-10-21.

- [`x86_64.md`](x86_64.md): the x86_64 table and the case against each offer not recommended.
- [`aarch64.md`](aarch64.md): why no aarch64 cloud machine boots nife, the offers table, and the
  Oracle Ampere A1 experiment.
- [`oracle-a1.md`](oracle-a1.md): the runbook for that experiment: the disk, the import, the
  console, and what it can cost.
- [`riscv64.md`](riscv64.md): the one RISC-V offer, the free runners that cannot boot a kernel, and
  why no rental substitutes for radon.
- [`a-second-provider.md`](a-second-provider.md): a second x86_64 provider as an experiment, the
  side-by-side table of delivery, console and power, and what several vendors cost.
- [`settling-milestone-225.md`](settling-milestone-225.md): the price of one bench evening per leg,
  and why a rented machine substitutes for xenon and argon in a soak and nowhere else.

*Name: provisional. The directory follows §212 (a prose budget)'s siting default, `notes/X/`
beside `notes/X.md`. calef names directories.*
