how it differs from a program's, where it lives, and its limits. The files here hold detail its
prose budget has no room for.

  `crates/capability_plan`, which its doc comments link.

stem in it. The directory follows the `notes/<stem>/` appendix convention §212 (a prose budget) set,
so its name is the parent's stem. Each file is named for its content, and calef names directories
and files.
