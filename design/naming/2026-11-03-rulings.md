# Naming rulings of 2026-11-03

*Name: provisional, minted 2026-11-03 for this stem. Naming is calef's.*

The rulings of 2026-11-03 (UTC), which [design/naming.md](../naming.md) summarizes. Each applies to
new and renamed names now. The sweep of existing names has not run.

## Units are spelled out

A name spells its unit: `_HERTZ`, `_MILLISECONDS`, `_MICROSECONDS`, `_NANOSECONDS`, `_BYTES`,
`megabits_per_second`. An SI symbol (`_HZ`, `_MS`, `_NS`, `mbps`) is not a valid suffix. Uppercase
constants erase the case that SI symbols depend on: `MHZ` and `mHz` become one name, and `_MS`
could be megasiemens. The micro sign has no ASCII symbol. Existing symbol names (about 95 across the
tree, including `TRANSFER_HZ`, `CARD_INTERFACE_UNIT_HZ` and `MATRIX_HZ` from #3092) await a separate
sweep. This replaces the 2026-10-26 ruling that `ms` and `us`
stay.

## `id` is an accepted word

`id` and `Id` stand: `ThreadId`, `device_id`, `DEVICE_IDS`. The standard library spells it
`ThreadId`, `TypeId` and `process::id`. Spell `identifier` out only where ID is one letter of a
compound specification acronym: `address_space_identifier`, `CardIdentification`,
`GloballyUniqueIdentifierPartitionTable`, `version_identification`.

## Where the standard library has a name, use it

Use Rust's spelling and match its meaning: `len`, `iter`, `iter_mut`, `get_mut`, `values`,
`contains`, `is_empty`, `peek`, `with`, and a `_mut` suffix for a method that returns `&mut`. A
reader who knows std then knows what the method does.

## No alias for an old nife spelling before first release

A crate carries no `#[doc(alias)]` for its own earlier spelling before its first release, since
nobody outside the tree has searched for it. Aliases for a specification or source term stay
(`rgmii`, `E1000_*`, a vendor or OpenBSD symbol, `csd`, `mbr`). After first publication a rename is
a breaking change, which is when an old-name alias could matter.

## Functions that answer yes or no

A function takes `is_`, `has_` or `can_`, or a third-person verb phrase such as `contains`. A bare
adjective or past participle is not a name for a function that runs something (`read_only`, `done`,
`required`).

## Register constants

- A constant for a register offset ends `_REGISTER`. A mask of several bits ends `_MASK`.
- A limit is `MAXIMUM_...` with the unit last: `MAXIMUM_FRAME_BYTES`.
- An assertion constant is `..._DO_NOT_OVERLAP`, without a leading `THE_`.
- Hardware names cite OpenBSD's spelling first, then FreeBSD's, then Linux's. The Intel `E1000_*`
  macros read the same in all three.
- The 2026-11-02 register rule overrides the 2026-10-26 ruling that the e1000e `registers` module
  keeps source names.
- When no source defines an abbreviation (`MULR` in `E1000_FEXTNVM11_DISABLE_MULR_FIX`), the name
  keeps it as written and the documentation says so. A name is a claim, and an expansion needs a
  source.

## Accepted acronyms

The accepted acronyms are `MAC` and `GMAC` (#3094) and `SD`. `SDIO` is not accepted, because it is the vendor's
label for a controller instance. `RGMII` becomes `reduced_gigabit_media_independent_interface`,
and `MDIO` becomes `management_data_input_output`.
