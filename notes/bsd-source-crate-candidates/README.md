# BSD crate candidates: the appendices to notes/bsd-source-crate-candidates.md

[`notes/bsd-source-crate-candidates.md`](../bsd-source-crate-candidates.md) carries the ranking, the
scoring and the method. These files carry what it was computed from:

- [measurements.md](measurements.md): every unit read in the BSD trees, with its lines, its license
  families and the share of its code outside kernel glue.
- [ecosystem.md](ecosystem.md): the closest Rust crate to each unit, with its downloads, newest
  release, license and `no_std` status.

Name: provisional, minted 2026-11-05 (UTC) by lane/bsd-crate-candidates, after the note it belongs
to. calef names things; expect this to change.
