[`notes/mutation-testing.md`](../mutation-testing.md) is the page to read; it is written so a reader
can act without opening anything here, and its appendix table is the index. These files hold the
per-crate triage and the dated censuses behind the current numbers.

*Name: provisional, minted 2026-09-24 by the lane that condensed the note (#1209) (`59580a880`), for
the directory and every stem in it. Naming is an architect's; `script/names --unratified` lists each
stem.*

## Which file holds a crate

One row per crate. A link is a section headed by the crate (a heading that names it in backticks, or
a plain list of crate names) or, marked "(row)", a table row whose first cell is the crate. The
"earlier names" are the names the ledgers use for a crate that was since renamed. The last column
counts the crate's rows in `notes/project-metrics/mutation-triage.csv`, the machine-read triage
file. The 2026-10-03 census's batch 6 rows are in
[census-2026-10-03-triage-batch-6-rows.csv](census-2026-10-03-triage-batch-6-rows.csv). The table is
generated by `helpers/mutation_ledger_index.py write`, and `script/lint` fails when it is stale.
