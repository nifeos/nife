# Adding a user program: the appendices to notes/adding-a-program.md

[`notes/adding-a-program.md`](../adding-a-program.md) carries the steps a newcomer follows to add,
check and remove a program, the manifest, and the `BUGS`, including the record of each walk. This
directory carries the reasoning its prose budget has no room for.

- [`why-it-works-this-way.md`](why-it-works-this-way.md): the reasoning of milestone 150 (adding a
  program should not need eight hand-maintained lists) for declaring a program once, and the
  designs it considered and refused.
- [`the-archives.md`](the-archives.md): how `xtask` packs the declared programs into the three
  initial ramdisks, what else each carries, and what packing refuses.

*Name: provisional. The directory follows the siting default of §212 (a prose budget), `notes/X/`
beside `notes/X.md`. calef names directories.*
- `why-it-works-this-way` Name: provisional. After the parent's "Why it works this way". calef names
  files.
- `the-archives` Name: provisional. After what the page describes. calef names files.
