# Soak: the appendices to notes/soak.md

[`notes/soak.md`](../soak.md) carries the instrument and the running record. These files carry what
the main page's prose budget has no room for: one bench evening's run table each, and the evidence
behind each section of the main page.

- [`qemu-baselines.md`](qemu-baselines.md): the first QEMU numbers, and what a soak build costs.
- [`migration-finding.md`](migration-finding.md): a saturated workload does not migrate, and why
  the soak extends `board_console`.
- [`tick-route.md`](tick-route.md): the mechanism that makes the soak cross cores, and its two bugs.
- [`placement-census.md`](placement-census.md): where the threads are, and the four QEMU runs.
- [`radon-2026-09-03.md`](radon-2026-09-03.md): the first runs off a board, and the three-hour run.
- [`radon-2026-10-10.md`](radon-2026-10-10.md): the run table of 2026-10-09 to 10.
- [`rebooting-soak.md`](rebooting-soak.md): why a rebooting soak, its hazard, and the reset radon
  cannot do.
- [`rebooting-soak-procedure.md`](rebooting-soak-procedure.md): the procedure and the outcome table.
- [`how-long-to-run-it.md`](how-long-to-run-it.md): the survey behind "no duration is prescribed".
- [`limitations.md`](limitations.md): the BUGS list in full.
